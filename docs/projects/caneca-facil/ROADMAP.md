# Caneca Fácil — Roadmap

## Phase A — Own Chat Foundation — COMPLETE
Provider-neutral chat, anonymous HttpOnly sessions, idempotent turns, SSE, durable history, private uploads, spacious customer shell, active Meta runtime retired.

## Phase B — Conversational AI — ACTIVE
1. Deterministic briefing engine: merge facts, explicit corrections, missing-info/readiness and minimum next question.
2. Versioned rich-component protocol with strict validation/fallback.
3. Backend-only structured AI interpreter/provider boundary.
4. Conversation orchestration combining interpreter + deterministic briefing + allowed actions.
5. Streaming AI text and validated components through existing SSE path.
6. Simulator/test mode using exactly the same engine.
7. Preserve `ai | human | paused` ownership semantics.
8. Acceptance: multi-turn scenario, corrections preserve unrelated facts, unsupported UI never reaches client.

## Phase C — Intelligent Storefront
Authoritative mug/model domain, tags/search, contextual recommendations, cards/carousels, browse mode, compare/select and project binding.

## Phase D — Creative Production
Reference interpretation, art generation, immutable versions, validation/correction, two-sided commercial/emotional mockup, revisions, approval and print-ready asset.

## Phase E — Commerce
Pricing/discounts, progressive identity, addresses, order/events, freight adapter, PIX adapter, confirmed payment and resumable checkout.

## Phase F — Operations & Automation
Live Admin conversation workspace, human takeover, production queue/gates, shipping/tracking, append-only events and idempotent automation worker.
